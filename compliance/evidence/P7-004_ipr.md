**Task:** P7-004 — IPR.1–IPR.8

## Defeito observado

Lifecycle DPA/ESC e heartbeat 501 por overlap de frequência existiam, mas não havia
domínio Rel1Ext de proteção: lista de DPAs a proteger (active / ESC absent /
disconnect / always-on), aggregate com clutter+loading, movelist, nem hooks de
grant/CPAS por critérios de interferência.

Follow-up: o path Rel1Ext usava Free Space **silenciosamente** quando ITM median
não era fornecido — resultado RF aparentava Type-3 ITM sem o ser.

## Alterações

- `services/dpa_protection.py` — `list_protected_dpa_channels`, Rel1Ext path loss
  toward DPA points, aggregate / greedy movelist, `proposed_grant_violates_dpa`.
- Path-loss policy (`DpaPathLossModel`):
  - default `ITM_REL1EXT` **exige** median ITM (injectável ou `load_itm_median_fn`);
  - **não** substitui ITM por Free Space;
  - ausência de ITM/NED → `DpaPathLossUnavailable` / evaluate fail-closed
    (movelist = todos overlapping; grant reject);
  - `FREE_SPACE` só quando o profile é selecionado explicitamente (lab/teste).
- `services/esc_admin_service.py` — `set_esc_absent` / `is_esc_absent` (IPR.1).
- `services/dpa_service.py` — refresh movelist on activate.
- `services/heartbeat_service.py` — movelist + ESC absent + always-on.
- `services/grant_service.py` — grant 400 on DPA neighborhood aggregate violation.
- `services/cpas_service.py` — refresh movelist + terminate `dpa_movelist`.
- `tests/unit/test_dpa_protection_ipr.py` — coortes + ITM/FS/fail-closed regressions.

`status` Rel1Ext IPR.* permanece `failing` (sem claim PASS / PASS_LOCAL / PASS_OFFICIAL).
